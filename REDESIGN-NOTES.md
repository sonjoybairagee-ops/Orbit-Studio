# CompX Orbit Studio redesign

- Black + brand-green Orbit design system
- Animated extension demo in the hero (Tools, Studio, Library scenes)
- Product ecosystem and multi-extension pricing presentation
- Existing Supabase auth, orders, license activation, downloads, device resets and admin APIs preserved
- Customer dashboard and admin panel inherit the new Orbit UI
- Added official CompX logo assets

## Run
1. Copy `.env.example` to `.env.local` and add your Supabase/payment/email values.
2. Run `npm install`.
3. Run `npm run dev` or `npm run build`.

## Interactive extension hero
- Clickable Tools, Studio, Motion, Colors, Tracker and Library rail tabs
- Clickable MOGRT, EXP, TEXT, SHAKE, SFX and FFX Library sub-tabs
- Auto-rotating feature tour; pauses while the visitor hovers
- Animated panels, mini feature previews, color swatches and responsive mobile layout
